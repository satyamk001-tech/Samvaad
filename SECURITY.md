# Security Policy

## Supported Versions

| Project Version | Supported          |
| :-------------- | :----------------- |
| 1.0.x           | :white_check_mark: |
| < 1.0.0         | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities privately by emailing:
**krsatyam1002@gmail.com**

Please include:
1. Steps to reproduce or proof-of-concept exploit payload.
2. Affected components (controllers, endpoints, drivers).
3. Potential impact.

Security disclosures will receive an acknowledgment within 48 hours.
